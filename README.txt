NEXORA DIGITAL WEBSITE — QUICK START

FILES
- index.html: complete responsive website
- README.txt: setup and publishing guide

1) PERSONALISE BEFORE PUBLISHING
Open index.html in Notepad or VS Code. Near the bottom, replace:
- https://payhip.com/b/REPLACE_WITH_YOUR_PRODUCT_CODE
  with the exact product URL copied from Payhip's product page.
- REPLACE_WITH_SUPPORT_EMAIL
  with an email address you actively monitor.

Do not publish until both placeholders are replaced.

2) PREVIEW
Double-click index.html to open it in Chrome or Edge.

3) PUBLISH FREE USING GITHUB PAGES
- Create a GitHub repository, e.g. nexora-digital-website.
- Upload index.html to the repository root.
- Open Settings > Pages.
- Choose Deploy from a branch, branch main, folder /(root), then Save.
- GitHub will display your public website address after publishing.

4) CONNECT A CUSTOM DOMAIN
- First buy a domain after checking availability, renewal price and registrar fees.
- In GitHub repository Settings > Pages, enter your custom domain.
- At your registrar, add the DNS records shown in GitHub Pages settings.
- Wait for DNS verification, then enable HTTPS when available.
DNS settings can change; use the current values displayed by GitHub, not an old tutorial.

IMPORTANT
- This is a static marketing website. Payhip handles the product checkout and digital delivery.
- Razorpay activation is separate. Do not claim Razorpay is enabled until approved and connected.
- Add accurate privacy, terms and refund policy pages before actively selling at scale.
- The site does not collect card details, passwords or other payment credentials.
